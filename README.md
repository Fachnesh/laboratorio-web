# Web Laboratory

A collection of small web projects created while learning HTML, CSS and JavaScript.

The purpose of this repository is to document my learning process, practise new concepts and build a portfolio step by step.

## Projects

| Project | Description | Status |
|---|---|---|
| `01-packliste` | Interactive packing list with categories, checkboxes and progress indicators | In progress |

## Repository structure

Each project has its own folder:

```text
project-name/
├── index.html
├── style.css
├── script.js
├── README.md
└── NOTES.md
```

- `README.md` explains the project, its purpose and the technologies used.
- `NOTES.md` contains learning notes, concepts, decisions and mistakes encountered during development.

## Learning goals

- Build semantic HTML structures.
- Style responsive layouts with CSS.
- Add interactive behaviour with JavaScript.
- Understand the reason behind each part of the code.
- Document progress through clear and focused commits.
