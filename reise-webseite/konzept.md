# Projektkonzept

## Ausgangssituation

Die Webseite besteht bereits seit längerer Zeit und wird kontinuierlich erweitert. Sie dient neben ihrem eigentlichen Inhalt auch dazu, während der Ausbildung verschiedene Möglichkeiten der Webentwicklung praktisch auszuprobieren.

Die Seite wird mit WordPress aufgebaut und kombiniert Funktionen des Editors und verschiedener Plugins mit eigenen Anpassungen durch HTML, CSS und JavaScript.

## Ziele

Die Webseite soll schrittweise erweitert werden. Dabei sollen neue Funktionen nicht ausschließlich durch zusätzliche Plugins umgesetzt werden, sondern – wenn sinnvoll und überschaubar – auch durch eigenen Code.

Wichtige Ziele sind:

- übersichtliche und verständliche Benutzeroberfläche
- gute Darstellung auf mobilen Geräten
- interaktive Inhalte
- einfache Pflege der Inhalte
- praktische Anwendung von HTML, CSS und JavaScript
- sinnvolle Kombination von WordPress-Funktionen, Plugins und eigenem Code

## Aktuelle technische Elemente

Im Projekt werden bzw. wurden unter anderem folgende Elemente eingesetzt:

- interaktive Karten
- externe Verlinkungen
- Tabs zur Darstellung unterschiedlicher Inhalte
- Einbindung von Google My Maps
- dynamische Fortschrittsanzeige
- automatisch aktualisierte Inhalte abhängig von Datum und Uhrzeit
- responsive Darstellung für Desktop und Smartphone

## Geplante Funktionen

Aktuell ist unter anderem eine interaktive Checkliste geplant. Einträge sollen direkt auf der Webseite markiert werden können, ohne dafür den WordPress-Editor zu öffnen.

Der Bearbeitungsstand soll im Browser gespeichert und durch Fortschrittsanzeigen visualisiert werden.

## Technische Grundlage

### CMS
- WordPress

### Webtechnologien
- HTML
- CSS
- JavaScript

### Weitere Komponenten
- Gutenberg/Gutenverse-Blöcke
- Google My Maps
- WordPress-Plugins je nach benötigter Funktion

Die konkrete technische Umsetzung wird abhängig von der jeweiligen Anforderung gewählt.
